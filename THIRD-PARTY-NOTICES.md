# Third-party notices

## What is in this folder

This project contains **no third-party source code and no model weights**.
Everything in it was written for this project.

## What it needs to run

**Blender** - https://www.blender.org/download/ - is required, and it is
**not included here**. Blender is free software under the GNU General Public
License, and it is installed separately on your machine. This script talks to
Blender the way any other Blender add-on does: it is handed to Blender's
Python interpreter as a script to run.

Because Blender is a separate program that this script asks to do a job,
this script is not a derivative work of Blender, and Blender's licence does
not apply to this script or to anything you make with it.

The only other thing used is the Python standard library that ships inside
Blender.
